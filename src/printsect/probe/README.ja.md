# probe — C のソースのプリントプローブと、その一覧

[English](README.md) | 日本語

`psect-probe` は C のソースにデバッグ用の行（プローブ）を入れ、それぞれについて、どこに、なぜ入れ、
何を出力したかを覚えておき、自分が入れたものだけを正確に取り除いて、ファイルを元に戻します。単独で
動きます。printsect の中では `psect probe` です。

```c
    if (len <= 0) {
        printf("[PSECT-AI 1 rx] len=%d\n", len); /* PSECT-AI:rx #1 */
```

## コマンド

| コマンド | 内容 |
|---|---|
| `psect-probe add FILE LINE` | LINE の下にプローブを入れる（0 = 先頭）。`-t` でコード、`-g` でグループ、`-p` で目的、`-e` でヒットした・しなかった場合に何が分かるか |
| `psect-probe list [GROUP]` | ソースにあるプローブと、目的、最後の結果。`--quickfix` でエディタ用、`--check` は 1 つでもあれば終了コード 1 |
| `psect-probe verify` | 一覧とソースを突き合わせる：移動した、消えた、知らない目印 |
| `psect-probe clear [GROUP]` | エージェントが入れたプローブを取り除く。`--orphans` で、一覧にないエージェントの目印も取り除く |
| `psect-probe hits LOG` | ログファイル（`-` で標準入力）で、各プローブが出力したものを数える：ヒット数、行番号、出した `name=value` |
| `psect-probe note N TEXT` | プローブの記録に書き足す |

どのコマンドも `--json` と `--root DIR` を受け付けます。

## プローブの管理のしかた

- **目印が正。** プローブの各行の末尾には `/* PSECT-AI:group #n */` が付きます。一覧の行番号は手がかりに
  すぎず、`verify` で更新されるので、プローブの周りのファイルを編集してもかまいません。
- **`-AI` は printsect が入れた印。** 取り除くのはその行だけです。`-AI` のない目印（`/* PSECT #3 */`）は
  あなたのもので、残ります。人が編集したプローブの行は、残して知らせます。
- **番号は使い回さない**ので、古いログの `#7` は、いつも同じ 1 つのプローブを指します。
- **ファイルは 1 バイトも変えずに戻る。** 文字コード（UTF-8 か CP932、BOM の有無）、各行の改行、ファイルの
  最後が改行で終わるかどうかを保ちます。読み直して同じにならないファイルは扱わず、書き込みは途中で壊れない
  方法で行い、読んだあとに誰かが変えたファイルは上書きしません。
- **入れる位置を確かめる。** インデントは上の行に合わせ、マクロの `\` による行の継続は最後に残し、文の
  終わりでない行には警告を出し、含まれる関数を記録します。

## 設定（`printsect.yaml`、すべて省略可）

```yaml
marker:
  prefix: PSECT            # 目印と出力のタグ：PSECT-AI / [PSECT-AI 7 grp]
probe:
  template: 'printf("[{tag}] %s:%d\n", __FILE__, __LINE__);'   # -t がないとき
  encodings: [utf-8, cp932]
  extensions: [.c, .h, .cc, .cpp, .cxx, .hpp, .hh, .inc]
limits:
  active_probes: 20        # 同時にこれより多くは入れない
```

プローブのコードの中では、`{tag}` が `PSECT-AI 7 group` に、`{n}` が番号に、`{where}` が `file.c:61` に
なります。

## 書くファイル

| ファイル | 用途 |
|---|---|
| `.printsect/probes.json` | 一覧：番号、ファイル、行の手がかり、グループ、目的、期待、状態、結果、メモ |
| `.printsect/PROBES.md` | 同じものを人向けの表にしたもの。変更のたびに書き直す |

## 中身

| ファイル | 内容 |
|---|---|
| `cli.py` | コマンド。`marks()` でほかのツールにファイルごとのプローブを渡す |
| `ops.py` | 追加、確認、取り除き、メモ。起動の目印。実行結果を一覧に書く |
| `marker.py` | 目印と出力のタグの読み書き |
| `ledger.py` | 一覧と `PROBES.md` |
| `textfile.py` | ほかの行を変えずにソースファイルを読み書きする |
| `cscan.py` | C を軽く見る：含まれる関数、文の終わり |
| `hits.py` | 各プローブのヒットと、出力した値を数える |
